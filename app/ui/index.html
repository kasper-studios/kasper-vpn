Режим сети

Защита от уробороса: входящий трафик 127.0.0.1:17890 идёт только в удалённый VLESS outbound; весь остальной трафик sing-box — напрямую. Сервер/upstream не может быть настроен через этот же локальный порт. Если порт уже занят, VPN не запустится.

MTProto-прокси для Telegram

Активируйте режим «Telegram · MTProto» и добавьте прокси в Telegram по ссылке — она не меняется между запусками.

Движок sing-box

Установите sing-box ≥ 1.12 с поддержкой Clash API. Движок запускается и останавливается приложением, без терминала.

Linux: /usr/bin/sing-box · Windows: C:\Program Files\sing-box\sing-box.exe

Ключ не включён в исходники приложения.
